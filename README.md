# DynamicsShowcase

Демо-приложение, показывающее **все возможности UIKit Dynamics** — физического движка, встроенного прямо в UIKit (`UIDynamicAnimator`). Тёмная неоновая тема, заточено под запись экрана.

## Запуск

Открыть `DynamicsShowcase.xcodeproj` в Xcode → Run (⌘R). iOS 16+, без зависимостей, без ассетов, всё нарисовано кодом.

Быстрый переход к нужному экрану для записи: в схеме задайте переменную окружения `AUTO_OPEN_DEMO` = `0…6` — приложение сразу откроет соответствующее демо.

## Экраны и покрытие API

| Экран | API |
|---|---|
| 🌍 Гравитация | `UIGravityBehavior` (вектор меняется пальцем), `UICollisionBehavior` + `translatesReferenceBoundsIntoBoundary`, `UICollisionBehaviorDelegate` (вспышки + хаптика), эллиптические границы (`collisionBoundsType = .ellipse`) |
| 🧲 Snap | `UISnapBehavior` с настраиваемым `damping` |
| ⛓️ Цепи | `UIAttachmentBehavior` — якорная и item-to-item связи, перетаскивание через attachment к пальцу |
| 🚀 Push | `UIPushBehavior` — `.instantaneous` (сила = скорость флика, закрутка через `setTargetOffsetFromCenter`) и `.continuous` с вращающимся вектором |
| 🌀 Поля | `UIFieldBehavior` — все 10 типов: radial, spring, vortex, noise, turbulence, velocity, linear, drag, electric, magnetic (заряд через `UIDynamicItemBehavior.charge`), `UIRegion` |
| ⚖️ Свойства | `UIDynamicItemBehavior` — `elasticity`, `density`, `resistance`, `addLinearVelocity`, граница-«пол» через `addBoundary(withIdentifier:from:to:)` |
| 🎪 Плейграунд | всё вместе + `UIDynamicItemGroup` (домино-пары по долгому тапу), рампы-границы, магнит двумя пальцами |

## Сценарий записи (~60 сек)

1. **Меню** (2 c) — прокрутить список карточек.
2. **Гравитация** (8 c) — потапать, затем повести пальцем по кругу: все шары «переливаются» по стенам вслед за вектором гравитации.
3. **Snap** (6 c) — потапать по углам экрана на «Упругий 0.2», переключить на «Вязкий 0.9», потапать ещё.
4. **Цепи** (8 c) — схватить нижний шар, раскачать, бросить. Цепь качается как маятник.
5. **Push** (7 c) — пара резких фликов, шайбы рикошетят; включить «Постоянную тягу» на пару секунд.
6. **Поля** (15 c) — самое зрелищное: Radial → повозить пальцем (рой бегает за пальцем) → Vortex (воронка) → Spring (пульсирующее облако) → Velocity (фонтан).
7. **Свойства** (5 c) — тапнуть пару раз: наглядно видно разницу упругости.
8. **Плейграунд** (9 c) — накидать шаров на рампы, подержать долгий тап (домино-группа), финал — тап двумя пальцами: всё слетается в «магнит» и рассыпается.

Совет: в симуляторе хаптика не слышна, для записи со звуком тапов лучше физическое устройство + запись через QuickTime.
